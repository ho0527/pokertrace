PokerTrace 公開 API 說明

PokerTrace 的部分小工具提供公開 API，可以在你自己的網站、Discord 機器人或試算表裡直接呼叫，例如勝率計算與 ICM。本頁列出各端點的網址、參數與回傳格式，全部免費、不需要金鑰即可使用。
