# !errorpage/423

## 用途

自訂錯誤頁面子目錄，維護指定錯誤碼頁面或錯誤頁素材。

這一頁是 `frontend/tool/` 下未開放工具頁的**長期**鎖定頁（nginx 對這些路徑 `return 423`），不是暫時性的系統維護。2026-07-17 已把文案從「網站維護中」改為「此頁面尚未開放」，並比照其他錯誤頁補上 `errorcode` 顯示 423：舊文案會讓使用者一直等一個不會回來的「維護」。若日後要拿這一頁當真正的維護頁，請另外開一個頁面，不要改回舊文案。
